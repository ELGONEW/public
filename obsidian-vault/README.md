# Obsidian Vault — חבילת התחלה

ברוך הבא ל‑Vault שלך. זהו מבנה כללי וגמיש לניהול הידע שלך באובסידיאן,
מסונכרן דרך Git ומיועד לעבודה משותפת איתך ועם Claude.

## מבנה התיקיות

מבוסס על שיטת **PARA** עם תוספת של פתקים יומיים:

| תיקייה | מטרה |
|--------|------|
| `00 - Inbox/` | קליטה מהירה. כל רעיון או פתק חדש נוחת כאן קודם, ואחר כך ממיינים. |
| `10 - Notes/` | פתקים קבועים ואטומיים — הידע ה"מזוקק" שלך. |
| `20 - Projects/` | פרויקטים פעילים עם מטרה ותאריך יעד. |
| `30 - Areas/` | תחומי אחריות מתמשכים (בריאות, כספים, עבודה...). |
| `40 - Resources/` | חומרי עזר והפניות לפי נושא. |
| `50 - Archive/` | דברים שהסתיימו או כבר לא רלוונטיים. |
| `Daily/` | פתקים יומיים (Daily Notes). |
| `Templates/` | תבניות מוכנות לפתקים חדשים. |
| `Attachments/` | קבצים מצורפים (תמונות, PDF וכו'). |

המספור (00, 10, 20...) שומר על סדר קבוע ברשימת התיקיות.

## איך מתחילים

1. פותחים את התיקייה הזו ב‑Obsidian דרך **"Open folder as vault"**.
2. הולכים ל‑`Home.md` — זו לוח הבית שלך, נקודת הכניסה לכל מקום.
3. מפעילים את הפלאגין הפנימי **Templates** (Settings → Core plugins) ומכוונים
   את תיקיית התבניות ל‑`Templates`.
4. כדי לכתוב פתק חדש: יוצרים קובץ ב‑`00 - Inbox/`, ובהמשך מעבירים לתיקייה המתאימה.

## סנכרון Git

- אתה עובד מהאייפד עם **Working Copy** + Obsidian (Pull כדי לקבל שינויים,
  Commit + Push כדי לשלוח).
- Claude עובד על אותו ריפו מסשן ייעודי, יוצר ועורך פתקים ודוחף שינויים.

## כללי עבודה (להתאמה אישית)

- פתק אטומי = רעיון אחד. כותרת ברורה. מקשרים בין פתקים עם `[[קישורים]]`.
- שמות קבצים תיאוריים. תגיות (`#tag`) לקטלוג רוחבי.
- מה שלא בטוח לאן שייך — נשאר ב‑Inbox עד שמחליטים.
